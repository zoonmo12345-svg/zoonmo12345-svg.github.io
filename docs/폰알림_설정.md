# 폰 알림 켜는 법 (관리자가 처음 한 번)

레이드 출발 전에 상회원 폰으로 알림을 보내는 기능이다.
- **사이트를 켜둔 동안**의 알림은 아무 설정 없이 바로 된다 (데모 모드에서도 됨).
- **폰이 꺼져 있거나 사이트를 닫았을 때**도 오게 하려면 아래 설정이 필요하다. Supabase 연결(`설정방법.md`)을 먼저 끝내야 한다.
- 사이트가 `https://` 주소로 올라가 있어야 한다 (깃허브 페이지는 자동으로 됨).

## 1. 비밀 키 넣기
`D:\슈고상회\keys\` 에 키 두 개가 있다. **`vapid_private.txt` 는 절대 사이트 폴더(깃허브)에 올리면 안 된다.**
Supabase 대시보드 → **Edge Functions** → **Secrets** 에 두 개 추가:
- `VAPID_PUBLIC` = `vapid_public.txt` 내용 (`config.js` 의 `vapidPublicKey` 와 같은 값)
- `VAPID_PRIVATE` = `vapid_private.txt` 내용

## 2. 알림 보내는 함수 올리기
Supabase 대시보드 → **Edge Functions** → **Deploy a new function** → 이름 `raid-push` →
`supabase/functions/raid-push/index.ts` 내용을 붙여넣고 Deploy. **Verify JWT 는 끄기.**

## 3. 1분마다 자동으로 돌리기
대시보드 → **Integrations** → **Cron** 켜기 → **Create job**
- 이름 `raid-push` · 주기 `* * * * *` (매분) · 종류 **Supabase Edge Function** → `raid-push` 선택

## 상회원이 폰에서 켜는 법 (사이트 '내 정보'에도 적혀 있음)
### 아이폰 (iOS 16.4 이상)
1. 사파리로 사이트 열기
2. 아래 가운데 공유 버튼 → **홈 화면에 추가**
3. 홈 화면에 생긴 슈고상회 아이콘으로 들어와서 로그인
4. 내 정보 → **이 기기에서 알림 켜기** → 허용

### 갤럭시(안드로이드)
1. 크롬이나 삼성 인터넷으로 사이트 열고 로그인
2. 내 정보 → **이 기기에서 알림 켜기** → 허용
3. (선택) 메뉴 ⋮ → **홈 화면에 추가**

## 알림 시간
각자 내 정보에서 고른다: 1일 전 · 3시간 전 · 1시간 전 · 30분 전 · 10분 전 · 직접 입력(분).
내가 '참여'를 누른 레이드만 알림이 온다.
