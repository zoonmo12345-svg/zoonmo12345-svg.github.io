# 슈고상회 사이트 — 실제 운영 켜는 법 (처음 한 번, 약 10분)

지금은 `assets/js/config.js` 의 두 값이 비어 있어서 **데모 모드**다.
데모 모드에선 가입·글·쪽지가 각자 브라우저에만 저장되고, 관리자 계정은 `admin / admin` 이다.
아래 순서대로 하면 진짜 회원가입·게시판·레이드·쪽지·접속 중 표시가 돌아간다.

## 1. Supabase 프로젝트 만들기
1. https://supabase.com 접속 → 가입 (무료 요금제)
2. **New project** → 이름 `shugo` · DB 비밀번호 아무거나(적어두기) · 지역 **Northeast Asia (Seoul)**
3. 1~2분 기다리면 완성

## 2. DB 표 만들기
1. 왼쪽 **SQL Editor** → **New query**
2. `supabase/schema.sql` 내용을 통째로 붙여넣기 → **Run** → 'Success' 확인
   (나중에 이 파일이 바뀌면 다시 통째로 붙여넣고 Run 하면 됨. 여러 번 돌려도 안전)

## 3. 이메일 확인 끄기 (계정 이름만으로 가입하려고)
왼쪽 **Authentication** → **Sign In / Providers** → **Email** → **Confirm email** 끄기 → 저장

## 4. 사이트에 키 넣기
1. **Project Settings** → **API** 에서 **Project URL** 과 **anon public** 키 복사
2. `assets/js/config.js` 의 `supabaseUrl`, `supabaseAnonKey` 에 붙여넣기
   (anon 키는 공개돼도 되는 키. **service_role 키는 절대 넣지 말 것**)

## 5. 관리자 계정 만들기
1. 사이트에서 가입 (실제 운영에선 비밀번호가 6자 이상이어야 해서 `admin / admin` 은 안 됨. 예: 계정 `admin`, 비밀번호는 6자 이상으로)
2. SQL Editor 에서 아래 한 줄 실행 (계정 이름만 맞추기)
   ```sql
   update public.profiles set status = 'approved', role = 'admin' where username = 'admin';
   ```
3. 새로고침하면 왼쪽 메뉴에 **사이트관리** 가 생김

## 운영
- 가입 신청 → 사이트관리 › 가입 승인. 본캐 닉네임을 보고 상회원인지 확인한 뒤 승인
- 사이트관리 › 회원: 본캐 닉네임·사이트 닉네임·로그인 계정·비상연락처를 볼 수 있음. 비밀번호는 볼 수 없고 **재설정**만 됨 (새 비밀번호를 직접 적어서 정해줌)
- 홈 공지 → 사이트관리 › 홈 공지
- 다운로드 탭 켜기 → `config.js` 의 `showDownloads: true` + `downloads` 목록

## 무료 요금제 참고
- 1주일 동안 아무도 안 들어오면 프로젝트가 잠들 수 있음 → 대시보드에서 **Restore**
- 사진 저장 1GB, 동시 접속(접속 중 표시·쪽지 실시간) 200명까지 무료
